# Конструктор програми харчування

Веб-додаток для індивідуального розрахунку калорійності та БЖВ і побудови тижневого меню з рівноцінних (взаємозамінних за калорійністю) продуктів.

## Як користуватись

Просто відкрийте `index.html` у будь-якому браузері — інтернет не потрібен, встановлення не потрібне.

Якщо увімкнено GitHub Pages для цього репозиторію, додаток також доступний за посиланням (див. розділ Settings → Pages цього репозиторію на GitHub).

На телефоні сайт можна встановити як додаток (PWA): відкрийте посилання у браузері → меню → «Додати на головний екран» / «Встановити додаток». Після цього він працює офлайн.

## Що всередині

- Анкета клієнта та автоматичний розрахунок норми калорій і БЖВ (формула Міффліна–Сан Жеора).
- Активність рахується двома окремими питаннями: рух протягом дня (кроки, фізична праця) + тренування. Внески беруться з реальних витрат (≈40 ккал/1000 кроків, ≈350 ккал за тренування), а не з класичних множників 1,375/1,55 — вони завищують внесок тренувань у 3–4 рази. Діапазон 1,20–1,75.
- Норма рідини подана коректно: скільки саме ВИПИТИ (враховуючи чай, каву, компот) і скільки надходить із їжею.
- Конструктор тижневого меню: сніданок / перекуси / обід / вечеря з випадаючими списками рівноцінних продуктів.
- Автоматичний підбір грамів під УСІ чотири цілі одночасно — калорії, білки, жири, вуглеводи (координатний спуск + вибір найкращого з 20 варіантів дня).
- Видиме попередження, якщо ручна заміна вибиває день за межі норми.
- Список покупок на тиждень, друк/збереження у PDF.
- Трекінг ваги з графіком динаміки.
- Світла та темна теми (автовизначення + перемикач).
- Слот «Смаколик» за принципом гнучкої дієти 80/20 (частка налаштовується 0–20%).
- Виключення продуктів: пресети «вегетаріанське / без лактози / без риби / без глютену» + пошук по базі.
- Побутові міри поруч із грамами (яйця в штуках, олія в ложках, хліб у скибках), норма води, орієнтовний час прийомів.
- Кнопка «Поділитися посиланням»: програма пакується в лінк — клієнт відкриває і бачить готове меню.
- Автозбереження всіх даних у браузері + кнопка «Новий клієнт».
- Збереження та завантаження програми клієнта у файл (.json).
- Персоналізована рекомендація конструктора тренувань після готового результату — з прикладом програми та прямим зв’язком із тренером.
- База ~215 українських продуктів; готові страви (борщ, вареники, деруни, голубці) розподілені за своїми категоріями й позначені «≈», бо калорії залежать від рецепта. Можна додавати власні.

## Технічно

Статичний сайт без бекенду: `index.html` (уся логіка), `manifest.webmanifest` + `sw.js` + іконки (PWA, офлайн-режим).

При оновленні `index.html` підвищуйте версію кешу у `sw.js` (`nutri-konstruktor-v12` → `v13`), щоб користувачі отримали свіжу версію.
