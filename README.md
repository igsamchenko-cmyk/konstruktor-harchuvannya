# Конструктор програми харчування

Веб-додаток для індивідуального розрахунку калорійності та БЖВ і побудови тижневого меню з рівноцінних (взаємозамінних за калорійністю) продуктів.

## Як користуватись

Просто відкрийте `index.html` у будь-якому браузері — інтернет не потрібен, встановлення не потрібне.

Якщо увімкнено GitHub Pages для цього репозиторію, додаток також доступний за посиланням (див. розділ Settings → Pages цього репозиторію на GitHub).

На телефоні сайт можна встановити як додаток (PWA): відкрийте посилання у браузері → меню → «Додати на головний екран» / «Встановити додаток». Після цього він працює офлайн.

## Що всередині

- Анкета клієнта та автоматичний розрахунок норми калорій і БЖВ (формула Міффліна–Сан Жеора).
- Конструктор тижневого меню: сніданок / перекуси / обід / вечеря з випадаючими списками рівноцінних продуктів.
- Автоматичний перерахунок грамів при заміні продукту.
- Список покупок на тиждень, друк/збереження у PDF.
- Трекінг ваги з графіком динаміки.
- Світла та темна теми (автовизначення + перемикач).
- Слот «Смаколик» за принципом гнучкої дієти 80/20 (частка налаштовується 0–20%).
- Автозбереження всіх даних у браузері + кнопка «Новий клієнт».
- Збереження та завантаження програми клієнта у файл (.json).
- База ~100 українських продуктів; можна додавати власні.

## Технічно

Статичний сайт без бекенду: `index.html` (уся логіка), `manifest.webmanifest` + `sw.js` + іконки (PWA, офлайн-режим).

При оновленні `index.html` підвищуйте версію кешу у `sw.js` (`nutri-konstruktor-v5` → `v6`), щоб користувачі отримали свіжу версію.
